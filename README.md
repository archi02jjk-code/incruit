# 다시출근 v3: 공공 채용공고 매칭 리포트

공공 채용공고 API 4곳에서 공고를 모아, 군 경력자의 기본 프로필과 맞춰 **추천 / 검토 / 제외**로 나누고 공고마다 추천 이유를 3줄로 보여 주는 사이트입니다.

## 채용공고 출처

| 화면 이름 | 데이터 | 받는 곳 | 상태 |
|---|---|---|---|
| 나라일터 | 인사혁신처_공공취업정보 조회 서비스 | 공공데이터포털 [15156780](https://www.data.go.kr/data/15156780/openapi.do) | 실제 응답 형식으로 확인 완료 |
| 잡알리오 | 기획재정부_공공기관 채용정보 조회서비스 | 공공데이터포털 [15125273](https://www.data.go.kr/data/15125273/openapi.do) | 실제 응답 형식으로 확인 완료 |
| 잡아바 | 경기도 내 공공일자리 정보 | 경기데이터드림 | 서비스명을 .env에 넣어야 함 |
| 경기 민간채용 | 민간 채용정보 현황 | 경기데이터드림 | 서비스명을 .env에 넣어야 함 |

경기데이터드림 두 곳은 공개된 페이지에서 서비스명과 필드명을 확인할 수 없었습니다. 로그인 후 각 데이터의 'Open API' 탭에서 서비스명을 찾아 `.env`에 넣으면, 필드(공고명·기관명·접수일 등)는 이름 규칙으로 자동으로 찾습니다. 자동으로 안 맞으면 `.env`의 `GG_*_FIELDS`로 직접 지정하세요.

## 실행 방법

### 1. 그냥 열어 보기 (샘플 공고)
`index.html`을 더블클릭하면 가상의 연습용 공고 26건으로 화면이 열립니다.

### 2. 실제 공고로 보기 (내 컴퓨터)
1. [Node.js](https://nodejs.org) 18 이상을 설치합니다. 추가 패키지는 필요 없습니다.
2. `.env.example`을 복사해 `.env`로 이름을 바꾸고 키를 넣습니다.
   - `DATA_GO_KR_KEY`: 공공데이터포털 마이페이지의 **일반 인증키(Decoding)**. 나라일터와 잡알리오 **각각 활용신청**해야 합니다.
   - `GG_API_KEY`, `GG_PUBLIC_JOB_SERVICE`, `GG_PRIVATE_JOB_SERVICE`: 경기데이터드림 인증키와 서비스명
3. 이 폴더에서 `node server.js`를 실행하고 브라우저에서 http://localhost:3000 을 엽니다.
4. 화면 위쪽 네 칸에 출처별 상태(연결됨 / 키 없음 / 오류)가 나옵니다. 키가 없는 곳은 빼고 나머지로 리포트를 만듭니다.

`npm test`로 응답 변환 로직을 실제 응답 형식 샘플로 확인할 수 있습니다.

## 기본 프로필

- 최종 계급 / 전역 예정일 / 군 경력(년)
- 주요 사업 규모·역할 (예: 국방정보화사업 150억, 사업관리 담당)
- 핵심 경력 분야: 사업관리, 국방정보화, 정보보안, 비상대비·안전, 획득·조달, 군수·물류, 교육훈련, 행정·기획, 시설
- 어학 수준 (없음 / 기초 / 중급 / 상급 / 원어민 수준) + 시험·점수
- 희망 지역: 수도권 우선 (서울·경기·인천) / 이주 가능 지역
- 조사 범위: 조사 시작일, 이전 공고 처리, 출처 선택

입력값은 브라우저에 저장되어 다시 열어도 남아 있습니다.

## 매칭 방법

공공 API는 공고명, 기관, 접수 기간, 근무지(잡알리오는 고용형태·채용구분·NCS 직무까지) 정도만 줍니다. 그래서 공고명과 직무분야에서 단어를 찾아 점수를 매깁니다.

| 항목 | 점수 |
|---|---|
| 경력 연관 | 내 분야 1개 25점, 2개 이상 35점, 없으면 제외 |
| 군 경력 강점 | 국방·방산·비상대비·충무·민방위·예비역·제대군인 등 15점 |
| 직급 | 팀장·센터장·전문위원·개방형·4~5급 30점 / 경력·임기제·전문경력관·6급 20점 / 7~9급·위촉·시간선택제 5점 / 알 수 없음 10점 / 신입·인턴·시간강사·공공근로는 제외 |
| 지역 | 수도권 20점 / 이주 가능 12점 / 미지정 10점 / 그 밖은 제외 |
| 어학 | 해외·국제·영어 등 공고에서 어학이 '상급' 미만이면 추천 대신 검토, 상급 이상이면 5점 |

70점 이상 추천, 45~69점 검토, 그 아래나 마감된 공고는 제외합니다. 단어 목록은 `index.html`의 `FIELD_DICT`, `VET_WORDS`, `HIGH_WORDS` 등에서 고칠 수 있습니다.

추천 이유 3줄:
1. **경력**: 주요 사업·경력 분야가 공고의 어떤 업무와 이어지는지
2. **직급**: 계급·군 경력에 비해 직급이 맞는지
3. **조건**: 근무지(수도권/이주 가능), 군 관련 강점, 어학

## 폴더 구성

```
index.html        화면 (매칭 로직 포함)
api/jobs.js       /api/jobs: 4개 출처를 모아 JSON으로 반환 (Vercel 서버리스 함수로 그대로 사용)
lib/sources.js    출처별 API 호출과 응답 변환
server.js         로컬 실행용 서버 (.env 읽기)
test/             실제 응답 형식 샘플과 테스트
.env.example      키 설정 예시 (.env는 GitHub에 올리지 않음)
```

## 다음 단계

1. **GitHub**: 이 폴더를 저장소로 올립니다. `.gitignore`에 `.env`가 들어 있어 키는 올라가지 않습니다.
2. **Vercel**: 저장소를 연결하고 Settings → Environment Variables에 `.env`와 같은 값을 넣으면, `api/jobs.js`가 그대로 서버리스 함수가 됩니다.
3. **Supabase**: 매일 아침 공고를 모아 `jobs` 테이블에 쌓고(Vercel Cron), 프로필과 저장한 공고를 `profiles`, `bookmarks` 테이블로 옮기면 여러 기기에서 같이 쓸 수 있습니다.
4. **추천 이유 고도화**: 지금은 단어 규칙으로 만듭니다. 공고 원문을 Claude API로 읽게 하면 자격 요건·연봉까지 반영한 이유를 쓸 수 있습니다.
