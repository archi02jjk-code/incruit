내 정보를 입력하고 아래 맞춤 공고 보기를 누르면 결과가 나와요. * 표시는 꼭 골라 주세요.

핵심 역량*
반드시 포함 (선택, 최대 2개)
입력하면 이 단어가 들어 있는 공고만 남겨요. 두 개를 넣으면 둘 다 들어 있어야 해요. 비워 두면 따지지 않아요.
연봉이 적힌 공고 중 희망보다 낮은 공고는 빠져요. 연봉이 없는 공고는 남겨 둬요.
희망 지역*
고르지 않은 지역의 공고는 빠져요.

매칭 기준

  • 경력 연관 (최대 40점): 공고명·직무분야에 내 핵심 역량이 하나 맞으면 25점, 둘 이상이면 40점. 하나도 없으면 제외합니다.
  • 반드시 포함 (점수 없음): 단어를 입력하면 공고명·기관·직무·근무지와 공고 내용(원문)에서 찾고, 없으면 제외합니다. 두 개면 둘 다 있어야 합니다. 비워 두면 따지지 않습니다. 원문 내용은 나라일터·잡아바 공고만 읽을 수 있고, 잡코리아 등 외부 사이트 공고는 제목 기준으로만 판단합니다.
  • 군 경력 강점 (25점): 국방, 방산, 비상대비, 충무, 민방위, 예비역, 제대군인, 군무원, 육·해·공군, 해병대, 병무청, 방위사업청 같은 단어가 공고명이나 기관명에 있으면 더합니다. 군 조직이 낸 공고는 핵심 역량 단어가 없어도 역량 1개(25점)로 인정하되, 이때는 군 경력 가점을 겹쳐 주지 않습니다. 간호사·임상병리사·미용사·응급구조 등 별도 면허 직무는 제외합니다.
  • 직급 (최대 35점): 공고명의 직급(4급, 팀장, 전문위원, 나급, 가군 등)을 6단계로 나누고 최종 계급에 맞는 단계와 비교합니다. 맞으면 35점, 한 단계 높으면 25점, 한 단계 낮으면 20점, 두 단계 이상 높으면 15점, 두 단계 이상 낮으면 5점, 직급이 안 보이면 15점. 신입·인턴·시간강사·공공근로는 제외합니다.
    계급별 맞는 직급: 준장 이상·대령 → 3~4급·국장·과장급 / 중령 → 4~5급·과장급·팀장급 / 소령 → 5~6급·팀장급·책임급 / 대위·준위·원사 → 6~8급·책임급 / 상사 → 7~9급. 흔히 쓰는 대략적 대응이며 공식 환산표가 아니에요.
  • 희망 지역 (점수 없음): 고른 지역의 공고만 남기고 나머지는 제외합니다. 근무지가 정해지지 않은 공고는 남겨 둡니다.
  • 희망 연봉 (점수 없음): 공고에 연봉이 적혀 있고 그 최고액이 희망 연봉보다 낮으면 제외합니다. 월급·시급은 연봉으로 바꿔 비교합니다(시급은 월 209시간 기준). 희망 연봉을 골랐는데 민간 공고에 연봉이 없으면 점수가 높아도 추천 대신 검토로 둡니다. 공공기관 공고는 원래 연봉을 적지 않아 이 규칙을 적용하지 않습니다.
  • 어학: 공고명에 해외·국제·영어 같은 단어가 있는데 어학 수준이 '상급' 아래면 추천 대신 검토로 둡니다. 상급 이상이면 5점을 더합니다.
  • 60점 이상 추천, 40~59점 검토, 그 아래나 마감된 공고는 제외합니다. 조사 기간은 최초 등록일로 판단합니다.

공공 API는 공고명·기관·기간·지역 정도만 주기 때문에, 자격 요건과 연봉은 공고 원문에서 꼭 확인하세요.

샘플 데이터 파일을 바로 열면 연습용 가상 공고가 보입니다. node server.js로 실행하고 API 키를 넣으면 실제 공고로 바뀝니다.
